# Note Studio v2.0 — 多语言识谱练习

适合 iPhone Safari 与桌面浏览器的静态五线谱识谱训练。可使用 GitHub Pages 免费部署；不需要账号、后端或构建环境。

## v2.0 新增

- 可切换 **8 种界面语言**：简体中文、繁體中文、English、Deutsch、Italiano、Français、日本語、Ελληνικά。
- 页眉的 **语言 / Language** 菜单切换后立即生效，语言选择保存在当前浏览器中。
- 题目、设置、答题流程、统计、帮助、调号和音频状态都随语言切换。
- 主要答案**始终使用国际字母音名 A–G**，例如 `B♭4`，确保切换语言不会改变识谱目标；次要答案显示所选语言的常用音名。
  - 德语：`B4`（国际）→ `H4`（德语）；`B♭4` → `B4`；`F♯4` → `Fis4`。
  - 意大利语／法语、日语、希腊语显示本语言常用固定唱名（Do / Ré / ド / Ντο 等）。
  - 简繁中文使用固定唱名 Do–Re–Mi。
- 切换语言**不会重新出题、改变音高或抹掉答题进度**。继续使用 v1 的设置与答题记录存储键。

## 使用

1. 用五线谱的谱号、调号和音符位置，在心里判断音名。
2. 点击「显示答案并播放」（对应语言按钮）后会显示国际音名、语言对应音名，并播放所选钢琴或小提琴的声音。
3. 自行标记对错，点击下一题。此时才会记录对错。
4. 可设置高／低音谱号、调号数量、音域、临时记号和音色；统计留在本机浏览器，可以导出 JSON。

键盘：Space 显示答案，1 正确，2 错误，Enter 下一题，P 再播放。

## 从 v1.0 更新 GitHub Pages（保留旧练习记录）

1. **保持原仓库名和 GitHub Pages 地址不变**，不必创建新仓库。
2. 解压此 ZIP，把根目录里的所有文件和 `ap-audio/`、`vendor/` 两个文件夹上传到**原仓库的根目录**，替换旧的同名文件。`index.html` 必须在最外层。
3. 新增文件 `i18n.js`；`service-worker.js` 已更新离线缓存版本到 `note-studio-v2.0.0`。
4. 保持 Settings → Pages → `Deploy from a branch` → `main` → `/ (root)`。
5. 发布后打开原链接。如仍显示旧版，重新加载网页；旧的离线缓存可能需要再刷新一次。切勿通过清除站点数据更新版本，否则会删除该浏览器储存的练习记录。

## 离线和音源

`ap-audio/` 包含小提琴／钢琴逐音实录（共 72 个音轨），`vendor/` 包含 WebAudioFont 采样音色；越出录音音域的音使用内置采样兜底，小提琴音域以下转用钢琴。

首次联网成功且 HTTPS 访问后，Service Worker 会缓存必要文件；以后可离线练习。音频播放需要用户的点击操作，适合 iOS Safari。

直接离线打开 `index.html` 时，`file://` 的音频文件请求可能受浏览器限制；因此另提供一个将全部音源嵌入的 **Standalone.html**，可以直接在电脑离线打开。此单文件不提供 Service Worker 安装体验。

## 项目文件

- `index.html`、`styles.css`：页面和响应式布局
- `i18n.js`：8 语言文案、惯用音名、调式名称
- `music-core.js`：五线谱音高、调号、题目生成（与语言无关）
- `app.js`：渲染、切换语言、练习、记录
- `audio.js`：真实录音 + 乐器采样 + 兜底合成音
- `symbol-paths.js`：谱号与升降号矢量形状
- `service-worker.js`、`manifest.webmanifest`：离线缓存和主屏幕图标
- `ap-audio/`、`vendor/`：音源、依赖、许可证
- `tests/test_core.cjs`、`tests/test_i18n.cjs`：可用 Node.js 运行的验证脚本

许可与音源来源见 `THIRD_PARTY.md`。
